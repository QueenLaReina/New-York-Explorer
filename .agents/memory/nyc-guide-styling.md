**Rule:** Keep the existing guide information and established type pairing (Bodoni Moda, Great Vibes, Libre Baskerville, and DM Mono) when changing visual layout unless the user asks to change them.

**Why:** The user requested a reference-inspired layout while keeping the same information and font.

**How to apply:** Treat supplied editorial PDFs and images as layout or color references, not as source material that replaces the guide's content or typography.
