## 📌 Project Overview

This repository contains the HTML & CSS foundational review assignment completed as part of the **CodeSquad AI Sprint**. 

The goal of this assignment is to demonstrate core competencies in semantic HTML structure, modern CSS styling, responsive layout techniques, and digital accessibility (a11y) principles. These fundamentals directly support the front-end interface development for upcoming sprint deliverables.

---

## 🎯 Learning Objectives & Focus Areas

- **Semantic HTML5:** Structuring clean, accessible web markup using appropriate landmarks (`<header>`, `<main>`, `<section>`, `<nav>`, `<footer>`) rather than unsemantic container elements.
- **Accessible UI/UX (WCAG Alignment):** Implementing proper label-input associations, keyboard navigability, readable typography, and accessible color contrast.
- **CSS Styling & Layouts:** Utilizing Flexbox and responsive box-model properties to construct clean, adaptable card and container layouts.
- **Code Organization & Cleanliness:** Writing maintainable, well-commented code following modern web standards.
