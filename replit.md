## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 5000)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required for persistent dish uploads: `DATABASE_URL` — Postgres connection string
- Required for dish inspection and chat: `GEMINI_API_KEY` — Google AI Studio API key
- Without `DATABASE_URL`, dish uploads use in-memory storage and do not survive an API restart.

For local development, create a `.env` file in the repository root, beside
`package.json`. The API server and Drizzle config load it automatically:

```env
DATABASE_URL=postgresql://...
GEMINI_API_KEY=...
```

`.env` files are ignored by Git. This project uses PostgreSQL, so `MONGODB_URL`
does not configure its database.

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)
